# Picard

Application web fullstack permettant aux étudiants de commander des produits Picard depuis un distributeur réfrigéré sur leur campus : consultation du catalogue, panier, paiement, création et consultation d'un compte de fidélité, historique des commandes.


## Lancer le projet avec Docker

Prérequis : Docker Desktop

```bash
docker compose up --build
```
